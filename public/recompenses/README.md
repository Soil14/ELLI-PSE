# Dossier récompenses

Place ici les fichiers des récompenses des épisodes (vidéo MP4, PDF, audio MP3, images JPG, etc.).

Exemples :
- reward-ep1-phase1.mp4 (vidéo)
- reward-ep2-fiche.pdf (document)
- reward-ep3-audio.mp3 (audio)

Dans episodes.json, référence-les avec '/recompenses/nom-fichier'.
